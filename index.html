Edge detection
Gaussian blur + Canny edge detection finds sharp transitions. Contour approximation (Douglas-Peucker) isolates the largest quadrilateral — your document outline.

        

        

          
          
Perspective correction
Once four corners are found, getPerspectiveTransform + warpPerspective flattens the document to a top-down scan, just like a flatbed scanner.

        

        

          
          
OCR text extraction
When connected to the Python API, Tesseract OCR reads the text from the warped scan. Supports English by default — more languages can be added to the backend.

        

        

          
          
Browser fallback
Without the API, all detection runs in-browser via OpenCV.js (WebAssembly) — no data leaves your device and no internet needed after load.
