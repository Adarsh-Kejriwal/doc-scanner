Detected document

Edge detection

Gaussian blur + Canny edge detection finds sharp transitions. Contour approximation (Douglas-Peucker) isolates the largest quadrilateral — your document outline.

Perspective correction

Once four corners are found, getPerspectiveTransform + warpPerspective flattens the document to a top-down scan, just like a flatbed scanner.

OpenCV.js (WebAssembly)

All processing runs entirely in-browser — no data leaves your device. OpenCV compiled to WASM gives near-native performance for real-time detection.

Extend it

Pair with Tesseract.js for OCR text extraction, or add a Python backend with OpenCV + YOLOv8 for multi-document detection and classification.
